# Deep Learning Visual–Textual Entailment

This project demonstrates multimodal reasoning by combining visual and textual information using a DenseNet–BERT architecture.  
It was originally developed as part of an academic research component within the Master of Data Science program at RMIT University and is shared here to illustrate practical deep learning and model evaluation skills using open data.

## Overview
The model fuses image features extracted from DenseNet with text embeddings from BERT through a cross-attention mechanism to predict semantic relationships between visual and textual inputs (e.g., entailment vs. contradiction).  
This approach highlights how multimodal architectures can improve reasoning and alignment across data types.

## Files
- **VisualTextualEntailment.ipynb** – main Jupyter notebook containing model design, training, and evaluation.  
- **README.md** – project overview and background information.

## Key Features
- Uses open datasets for visual–textual entailment tasks.  
- Implements multimodal fusion using pre-trained visual and language models.  
- Demonstrates fine-tuning, loss tracking, and evaluation metrics such as accuracy and confusion matrices.  
- Includes qualitative visualisation for model interpretability.
