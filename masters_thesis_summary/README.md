# Master's Thesis Summary

This folder contains a non-confidential summary of my Master's research in Data Science at RMIT University.

## Overview
The thesis investigates advanced machine learning and evaluation strategies for generative AI models, focusing on model robustness, performance consistency, and interpretability.  
It demonstrates practical implementations of evaluation pipelines, custom metrics, and automated experiment runners using **open datasets**.

## Included Files
- **FengLin_MasterThesis.pdf** – summary version of the submitted thesis.  
- **config.py** – configuration template for experiments, specifying model and dataset parameters.  
- **metrics_runner.py** – implements metric aggregation and evaluation logic for model performance comparison.  
- **run_all_evals.py** – orchestrates end-to-end evaluation across multiple runs.  
- **single_usage.py** – example single-run evaluation using the same framework.  
- **requirements.txt** – minimal Python dependencies for reproducibility.

## Highlights
- Designed and implemented a unified evaluation framework for comparing model outputs across multiple runs and conditions.  
- Developed reproducible metric runners supporting both standard and custom-defined metrics.  
- Integrated results with visual and statistical analysis to assess model calibration and performance stability.  

## Notes
All code is original and uses **open, publicly available data sources** for demonstration.  
No institutional, confidential, or partner data are included.
