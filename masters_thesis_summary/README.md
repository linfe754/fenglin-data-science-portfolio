# Master's Thesis Summary

This folder contains a non-confidential summary of my Master's research in Data Science at RMIT University.  
The thesis focuses on generative AI and data-driven modelling for real-world analytical applications.

## Project Overview
- Developed and evaluated advanced data science and machine learning methods for applied analytics and simulation.
- Integrated statistical modelling and AI techniques to improve interpretability and forecasting accuracy.
- Demonstrated end-to-end analytical workflows including data preparation, model development, evaluation, and result communication.
